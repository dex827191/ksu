DNS protection / mapping

HEV maps UDP DNS requests to synthetic IP addresses so hostname connections can be resolved through the tunnel. Enable GLOBAL ROUTING for the redirect to reach HEV. This handles IPv4 UDP port 53 only; encrypted DNS (DoH/DoT) and IPv6 DNS are not redirected.

Security and performance

Secrets are stored locally with file permission 0600. Strict host-key mode requires a trusted known_hosts entry. The current SSH forwarding engine supports TCP CONNECT; general UDP forwarding is not implemented.
